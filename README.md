# Frontend del Gestor de Eventos

Este es el frontend de la Aplicación Full-Stack de Gestión de Eventos, construido con React y Vite.

## Tecnologías Utilizadas

- **React:** Biblioteca principal para la construcción de la interfaz de usuario.
- **Vite:** Herramienta de construcción y servidor de desarrollo ultrarrápido.
- **Axios:** Para realizar peticiones HTTP a la API del backend.
- **React Router Dom:** Para el enrutamiento y navegación entre las distintas páginas.

## Instrucciones de Instalación

1. **Instalar dependencias:**
   Abre una terminal en este directorio (`frontend`) y ejecuta el siguiente comando:
   ```bash
   npm install
   ```

2. **Ejecutar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   Esto iniciará Vite y te proporcionará una URL local (usualmente `http://localhost:5173/`) para visualizar la aplicación en tu navegador.

## Estructura Principal

- `src/components/`: Componentes reutilizables de la interfaz gráfica (por ejemplo, `Sidebar.jsx`).
- `src/pages/`: Páginas principales de la aplicación (como `Login.jsx`, `Register.jsx`, `Events.jsx`, `Categories.jsx`).
- `src/context/`: Contexto global de la aplicación (por ejemplo, `AuthContext.jsx` para el estado de autenticación del usuario).
- `src/services/`: Configuración centralizada de Axios y llamadas a la API (`api.js`).
